Rules specific to `ur.po`.

## Use Urdu-Indic numerals for all numbers

Always write numbers using Urdu-Indic digits, not Western Arabic digits. This matches the established convention throughout the catalog.

| Western | Urdu-Indic |
|---------|------------|
| 0       | ۰          |
| 1       | ۱          |
| 2       | ۲          |
| 3       | ۳          |
| 4       | ۴          |
| 5       | ۵          |
| 6       | ۶          |
| 7       | ۷          |
| 8       | ۸          |
| 9       | ۹          |

Examples from the catalog: "1 day" → "۱ دن", "10 minutes" → "۱۰ منٹ", "30 days" → "۳۰ دن".

This applies to all numeric literals that appear in translation strings, including those embedded in sentences.
